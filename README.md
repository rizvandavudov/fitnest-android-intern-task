# FitNest Android Intern Task

Android internship technical assignment implemented with Kotlin and
Jetpack Compose.

## Design assumptions

### Typography

The provided Figma design uses SF Pro, SF Compact Rounded, and Poppins.

SF Pro and SF Compact Rounded are not bundled with this repository. Android's
system sans-serif font family is used as the closest platform-appropriate
fallback while preserving the Figma font sizes, weights, line heights, and
letter spacing.

Poppins Regular is bundled from the official Google Fonts repository and is
used for the FitMarket title as specified in the Figma design. Its SIL Open
Font License is available at `docs/Poppins-OFL.txt`.
